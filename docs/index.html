You are the shepherd now, ship it.

sheepit puts every terminal on your machine into one browser tab. Run one command where your code is, open it from any device on your network, and each shell — each Claude Code, Codex or Hermes session — gets a pen of its own: fenced, named, and honest about whether it is working, finished, or waiting on an answer from you.

One tab instead of five apps

A terminal, a runtime for coding agents, a file viewer, an editor and your notes — all in the browser

Not a cloud service and not an editor bolted onto a shell. One npm package, running on the machine your code is on, serving all five of these over your own network.

Works from anywhere

The machine stays put. You don't.

Your shells live on the computer your code is on, and everything else is just a screen pointed at it. Answer a waiting agent from the sofa, check a build from the kitchen, hand a pane to the tablet already in your hand — the session never moved, so nothing was interrupted.

  • Any device on your network — phone, tablet, the other laptop
  • From outside it over an SSH tunnel, or your own private network
  • Installable to the home screen, with the bleating count in the header
  • Close the tab and the work carries on without you

Open the gate

One command, then localhost:4444

Node, and nothing else. No tmux, no config file, no account.

$ npx @nicoloboschi/sheepit # or keep it around $ npm install -g @nicoloboschi/sheepit $ sheepit --host 127.0.0.1

Mind the gate

sheepit hands the browser a real shell on the host and it has no authentication. By default it binds 0.0.0.0 — anyone who can reach the port has your machine.

Run it on 127.0.0.1 and reach it over an SSH tunnel: ssh -L 4444:localhost:4444 you@host. Never put it on the open internet without auth and TLS in front.
